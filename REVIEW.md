# Content review list

Every checklist in `aircraft/` was drafted from typical manufacturer procedures, not from a specific
approved document. Before anyone flies with it, each type must be checked line by line against the
POH/AFM for the actual airframe. The items below are the ones the authors were least sure of, so
start there. Tick them off here as they are verified.

## Cessna 152
- [ ] Va 93 KIAS at 1,500 lb (104 at 1,670 lb)
- [ ] Suction range 4.5–5.4 in Hg
- [ ] Emergency-descent speeds (not a 152 POH procedure; Vno/Va used)
- [ ] Door-open speed 65–70 KIAS (reasonable value, not a POH number)

## Cessna 172S
- [ ] Vs/Vso 48/40 KIAS
- [ ] Standby battery test (hold TEST 20 s, green light steady) and ~30 min essential-bus endurance
- [ ] G1000 display-failure wording ("Display Backup" button)
- [ ] Emergency-descent speeds (not in the 172S POH; Vno/Va used)

## Cessna 182T
- [ ] Vfe bands 140 (10°) / 100 (10°–20°) and whether FULL flap is 20° or 30°
- [ ] Vs/Vso 49/41; approach 70–80 flaps up / 60–70 full
- [ ] Climb 23 in Hg / 2,400 RPM at 85–95 KIAS; prop-cycle drop 300–500 RPM
- [ ] Forced-landing speeds 75/70 KIAS

## Cessna 206H
- [ ] Whole V-speed set (Vs/Vso 58/54, Va 121/111/101, Vfe 140/120/100, Vno 149, Vne 182, glide 80, Vx 72, Vy 88) – least certain set
- [ ] Oil 12 qt max / 9 qt min; climb 25 in Hg / 2,500 RPM
- [ ] Tank-switching practice lines (operating practice, not POH text)
- [ ] Exact cargo-door / flap interlock mechanism and emergency release location (POH Section 3 and placards)

## Cessna 208B
- [ ] Entire file: original prototype content supplied with the first version; operator checklist may differ

## Piper PA-28-161 / PA-28-181
- [ ] Rotation speeds 50–60 / 52–60 KIAS (POH wording varies by year)
- [ ] Warrior cruise RPM 2,300–2,600; Archer cruise-climb 87 KIAS
- [ ] Oil temp 245°F, vacuum 4.8–5.2 in Hg, idle 500–700 RPM, fuel pressure 0.5–8 psi (standard figures)

## Piper PA-28R-201 Arrow
- [ ] Fuel pressure arc 14–45 psi
- [ ] Auto-extension speed ~95–105 KIAS; emergency extension 87 KIAS; Vlo 107 retract / 129 extend (Arrow III; IV may differ)
- [ ] Gear-horn triggers (~14 in Hg, flaps beyond 10°) vary by serial

## Piper PA-44-180 Seminole
- [ ] Both-engines-out glide 105 KIAS (training figure)
- [ ] Feather check 1,500 RPM / ~500 RPM drop; emergency extension below 100 KIAS; horn ~14 in Hg
- [ ] Alternator ~60 A, battery ~30 min
- [ ] Shutdown: fuel selectors ON (POH) vs OFF (operator)

## Beechcraft A36 Bonanza
- [ ] Prop cycle RPM in run-up (1,700 used; some checklists 2,000)
- [ ] Vs/Vso ~64/52 KIAS; engine-failure-after-takeoff 85–90 KIAS
- [ ] Hand-crank stowage location

## Beechcraft Baron 58
- [ ] Feather check 1,500 RPM / ~300 drop / return before 1,000; prop cycle 1,700 RPM
- [ ] Which engine to start first (not stated in the file)
- [ ] Vs/Vso 84/75, Vx 92, Vy 105, Vref 95, full-flap Vfe 122
- [ ] Aux fuel pumps OFF (LO if fluctuating) for takeoff and landing – check model year
- [ ] Gear indicator: one light (early) vs three (later)

## Cirrus SR20
- [ ] G3 speeds used (Vx 81, Vy 96, glide 87–88, Vfe 119/104, Va 130, Vno 163, Vpd 133, Vs/Vso 65/56); G6 differs
- [ ] Mag check 1,700 RPM, 150/75; oil 30–60 psi; CHT 460°F / oil 240°F
- [ ] CAPS descent ~1,700 ft/min, ~3 g touchdown; Bat 2 ~30 min

## Cirrus SR22
- [ ] G3 Vfe 119/104 vs G5 150/110
- [ ] Alt 2 rating (~20 A G3; G5 value to confirm)
- [ ] Vs/Vso ~73/60; Bat 2 ~24 V; prime 2–3 s; BOOST pump schedule
- [ ] 500 ft AGL branch in engine failure after takeoff is training guidance, not a POH limit (400 / 920 / 2,000 ft are POH figures)
- [ ] Mag check 150/75 RPM tolerance

## Mooney M20J
- [ ] Vx 66–70, Vy 91 (some sources 93), Vfe 110–115, Vs/Vso ~61/55, Vr 60–65
- [ ] Manual gear extension stroke count (~12–20) and lever sequence
- [ ] Mag check 2,000 RPM, 175/50; boost pump ON for takeoff/landing; oil 25 psi min / 60–90 normal
- [ ] Alternate air: manual control fitted or automatic door

## Diamond DA40
- [ ] Vr 59, best glide 88 KIAS
- [ ] Mag check 2,000 RPM, 175/50; prime method; starter 10 s on / 20 s cool; min oil 75°F; CHT 500°F
- [ ] Battery ~30 min; long-range tank transfer-pump logic

## Diamond DA42 NG
- [ ] Vx 84 / Vy 90 / Vxse 82; Va 125; Vno 155; idle ~890 RPM
- [ ] Min oil 50°C / coolant 60°C; fuel transfer trigger (~2/3 main); free-fall time ~30 s
- [ ] ECU switch nomenclature (A / AUTO / B) and ECU TEST layout vary by serial; starter cooling 2 min
