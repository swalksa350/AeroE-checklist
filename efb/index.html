AeroE Checklist – EFB files

Single-file versions of each aircraft checklist for loading into an EFB's Documents area (OzRunways, AvPlan and similar). The interactive HTML file works offline inside the EFB once loaded; the PDF is a printable fallback. The main app is the master copy and is updated first.

Loading into OzRunways (iPad / iPhone):
  1. Tap an "Interactive (HTML)" link below, then use Share → Copy to OzRWY. It appears on the Documents page, where you can move it into a folder.
  2. Or save the file to a Dropbox folder linked in OzRunways Settings; it syncs to the Documents page.
  3. Companies can push files to every pilot through the OzRunways Dashboard.
Loading into AvPlan EFB:
  1. Save the file into the Apps/AvPlan EFB folder of a linked Dropbox account; it appears under Text → Dropbox. AvPlan's Dropbox import is documented for PDF, so test the HTML file on your device first and use the PDF if it does not open.
  2. Cloud Group administrators can distribute files to members.

Ticks and day/night choice are remembered only where the EFB's viewer allows browser storage. Files are from version 1.9; replace them when the main app updates. Prototype content – verify against the POH/AFM before any use.
